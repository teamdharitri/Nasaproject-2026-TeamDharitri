For every row in the tables below:

- **Y/N answers:** wherever a cell says `[Y/N]`, write **Y** for Yes or **N** for No
- **Usage:** write `AI`, `Non-AI`, `Both`, or `N/A` (we did not do this task)
- **Tool(s):** the AI tool or normal software used (leave blank for pure manual work)
- **What was done:** one short, specific sentence
- **Done by:** the team member(s) responsible
- **Human review:** what we checked or changed before using it

> **Key:** Y = Yes, N = No, N/A = not applicable (task not done).
>
> Replace every `[placeholder]`, delete rows that do not apply, and add rows for anything missing. Only write what is true.
